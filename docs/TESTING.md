# 验证范围

`./scripts/test.sh` 在隔离目录执行，不读取或修改真实待办。

覆盖：

- 完成到步骤 3 后改为步骤 2，后续步骤清空。
- 重复选择同一步保持进度不变。
- 最后一步完成后，事项从小组件待办中移除。
- 第一步点亮后再次点击清空，保存恢复为零，再次点击可重新开始。
- 默认单项事项完成后保持完成，不触发第一阶段重置。
- 紧急 / 一般 / 不急 / 无优先级的保存恢复。
- 旧版没有 priority 字段的数据解码。
- 自定义分类去重、共享存储保存恢复、旧快照合并和上一版备份。
- 使用真实 App Intent 的 `perform()` 逻辑与 Provider 过滤逻辑。

构建及签名验证在 Apple Silicon Mac、macOS 27.0、Xcode 27.2 本机执行。系统已成功登记 WidgetKit 扩展；本机使用者已从桌面列表添加大号小组件。
